# 智慧乡村村务综合管理系统 - 需求规格说明书

版本：V1.3（对照系统实际实现整理） · 日期：2026-08-03

## 1. 项目背景与目标

面向行政村治理场景的局域网离线村务管理系统，实现村务台账数字化、档案集中管理、数据自动预警、收缴情况可视化，替代纸质台账，提升基层治理效率。

**部署约束**：局域网离线部署、单机集中存储、禁止外网访问；服务主机最低双核/4G/50G/Win10-11。

## 2. 角色与权限

| 角色 | 编码 | 权限 |
|------|------|------|
| 超级管理员 | admin | 全部功能（含系统管理、备份恢复、年度封存、字段/菜单配置） |
| 普通管理员 | manager | 台账增删改查、导入导出、预警处理、归档管理 |
| 只读用户 | viewer | 仅查看，禁止任何新增/修改/删除 |

- 默认管理员 `admin/admin123`，不可删除、不可禁用。
- 敏感信息（身份证、手机号）列表默认脱敏展示，编辑场景除外。

## 3. 功能需求（EARS）

### 3.1 台账管理（24 套）

系统 应 提供以下 24 套台账的增删改查、批量导入（xlsx、身份证查重跳过）、自定义导出（字段可勾选/模板复用）、单条打印、数据查重：

- **基础人口（7）**：村民信息、党员信息、残疾人信息、低保信息、三费收缴、水库移民、一般搬迁
- **民政特殊（5）**：困难救助、留守儿童、老年人、现役退役军人、境外人员
- **村级治理（12）**：三资管理、宅基地建房、防溺水、信访矛盾、村务公开、公益性岗位、移风易俗（红事统计表/白事统计表）、乡村产业、工程项目、走访帮扶

当 用户点击"新增/编辑"时，系统 应 弹出动态表单，字段按元数据配置展示与校验。

当 用户点击"导出"时，系统 应 按当前列表字段或已存模板生成 Excel。

### 3.2 零代码字段与菜单配置

当 管理员打开"台账字段配置"时，系统 应 支持新增自定义字段（text/number/date/image/select）、调整顺序、列表/表单/导出显示开关、必填设置，以及删除入回收站、一键恢复。

当 管理员打开"菜单配置"时，系统 应 支持新增/隐藏/排序一级、二级菜单。

约束：系统内置字段锁定不可删除；自定义字段物理列事务化创建，异常自动回滚。

### 3.3 智能预警中心

系统 应 每日自动扫描台账并生成待办预警，同时支持手动触发扫描。预警分红色（紧急）/黄色（预警）两级。

已知规则（与需求明细对应）：

| 台账 | 预警规则 |
|------|----------|
| 残疾人信息 | 残疾证到期前 30 天预警；已过期转红色 |
| 党员信息 | 党费欠缴预警 |
| 留守儿童 | 距上次走访超 `visit_warn_days`（默认 30）天未走访预警 |
| 工程项目 | 合同到期/工期节点临近预警 |
| 公益性岗位 | 合同到期续签预警 |
| 村务公开 | 距公示到期 `public_warn_days`（默认 3）天预警 |
| 三费收缴 | 未缴费名单生成催缴预警 |

当 用户办结预警时，系统 应 记录处理人/时间/说明；逾期可延期处理。

### 3.4 文档智能归档

系统 应 支持 Word/Excel/PDF/JPG/PNG 多选与整文件夹上传，按内置关键词库自动归类到对应台账，未匹配可手动归类或一键智能扫描归类；支持关联村民（一户一档）、在线预览、下载、删除。Excel 可导入台账；证件图片可 OCR（部署包内置 PaddleOCR 时启用）。

### 3.5 三费收缴面板

系统 应 按年度展示医保、养老、大病补充三费收缴总览与村组对比。

三费收缴率三色规则：绿色 ≥80%（正常）、黄色 50%~80%（预警）、红色 <50%（紧急）。

当 用户点击未缴村组时，系统 应 展示未缴名单并支持导出催缴名单。

### 3.6 村务数据大屏

系统 应 提供八大专题离线大屏：人口治理、党建信息、特殊群体、三费收缴、搬迁安置、产业项目、平安综治、预警信息；底部滚动展示待办预警，数据实时刷新。

### 3.7 系统管理

- 用户账号管理：新增/启停/重置密码/角色分配
- 操作日志：全部写操作永久审计，不可删除
- 数据备份恢复：手动/定时（默认 02:30）加密备份、一键恢复、备份天数保留
- 年度数据封存：年末封存当前年度全部台账至 `t_*_{year}` 存档表并清空原表，封存前自动备份
- 系统参数配置：村名、备份时间、预警阈值等
- 登录锁屏：离开时可锁定，密码解锁

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 部署 | 局域网单机离线部署，前端构建产物由后端一体化托管，单端口访问 |

| 扩展性 | 台账、菜单、字段均零代码可配置，新增台账无需改代码 |
