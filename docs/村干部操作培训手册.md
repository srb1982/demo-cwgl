# 智慧乡村村务综合管理系统 - 村干部操作培训手册

文档编号：ZW-CW-20260731-TR · 适用版本：V1.3（React 前端版）

## 一、登录系统

1. 打开浏览器（Chrome / Edge）。
2. 地址栏输入服务主机地址：`http://主机内网IP:8000`。
3. 输入管理员分配的**用户名**和**密码**，点击"登录"。
4. 为保护隐私，身份证号、手机号在列表中自动脱敏显示（如 `1101**********1234`）。

## 二、界面说明

- **左侧菜单**：基础人口台账、民政特殊人群、村级治理业务三大台账分组，以及文档归档中心、智能预警中心、三费收缴面板、村务数据大屏、系统管理。
- **顶部栏**：村名、预警铃铛（数字为待办预警数，点击直达预警中心）、右上角账号菜单（锁屏/退出）。
- **屏幕锁定**：点击账号 → 锁屏，输入登录密码解锁，防止离开时信息泄露。

## 三、台账操作（22 套台账通用）

### 新增记录
1. 进入任一台账（如"村民信息台账"）。
2. 点击右上角"新增"，弹出录入表单，按提示填写。
3. 带 `*` 为必填项；下拉项直接点选；日期点击日历选择；图片字段点击上传。
4. 点击"保存"。

> 小技巧：填写身份证号后，出生日期等可通过系统自动计算，减少重复录入。

### 编辑与删除
- 行末"编辑"修改记录；"删除"需二次确认，防止误操作。

### 条件筛选与搜索
- 顶部搜索框输入姓名、证件号等关键字快速检索。
- 下拉选项列（如"性别""村民组"）可点击表头漏斗图标按值筛选。

### 批量导入
1. 点击"批量导入"，下载参考格式（表头需与字段名称一致，如：姓名、身份证号、联系电话）。
2. 选择 `.xlsx` 文件上传，系统自动校验并跳过身份证重复数据。

### 导出与打印
- 点击"导出"，勾选需要导出的字段，可"保存为模板"供下次直接复用。
- 行末"打印"可将单条登记表打印归档。

### 数据查重
- 点击"数据查重"，自动检查身份证号、户号重复记录并标红提示，及时更正。

## 四、文档智能归档中心

1. 点击"上传文档"，可**多选**或**整文件夹**上传 Word/Excel/PDF/JPG/PNG 文件。
2. 系统按内置关键词**自动归类**到对应台账（也可点"智能归类"对未归类文件批量匹配）。
3. 行末"关联"：将文件关联到具体村民，实现**一户一档**（合同、证件、走访影像等统一归档）。
4. 支持在线预览、下载、删除。
5. Excel 文件可在台账页"批量导入"直接入库；证件图片支持 OCR 识别（部署包内置 PaddleOCR 时启用）。

## 五、智能预警中心

- 系统**每日自动扫描**全部台账，生成待办预警（如残疾证到期、党费欠缴、留守儿童超期未走访、工程工期节点、公益岗位续签、村务公示到期等）。
- 预警分级：**红色=紧急，黄色=预警**。
- 处理方式：办结（填写处理说明）或延期处理。
- 右上角"立即扫描"可手动触发一次扫描；"导出清单"可导出全部预警到 Excel。
- 顶部预警铃铛有红色数字提示待办数量。

## 六、三费收缴面板

- 顶部切换**年度**，查看医保、养老、大病补充三费收缴总览。
- 村组收缴率三色标识：**绿色 ≥80%（正常）、黄色 50%~80%（预警）、红色 <50%（紧急）**。
- 点击村组"查看未缴名单"，弹窗列出本组未缴费村民，一键导出催缴名单。

## 七、村务数据大屏

- 授权账号点击"村务数据大屏"，全屏展示人口治理、党建信息、特殊群体、三费收缴、搬迁安置、产业项目、平安综治、预警信息八大专题。
- 底部滚动展示待办预警清单，适合工作汇报与迎检场景。
- 大屏可长时间挂屏运行，数据实时刷新。

## 八、系统管理（仅超级管理员）

| 功能 | 说明 |
|------|------|
| 用户账号管理 | 新增账号、启用/禁用、重置密码，分配三种角色 |
| 菜单配置 | 新增/隐藏/排序一级、二级菜单 |
| 台账字段配置 | 拖拽调整字段顺序、新增自定义字段、开关显示、必填设置、回收站恢复 |
| 操作日志 | 查询、导出全部操作记录（不可删除） |
| 数据备份恢复 | 手动/自动备份、恢复、年度封存 |
| 系统参数配置 | 村名、备份时间、预警阈值等 |

### 三种角色权限

| 操作 | 超级管理员 | 普通管理员 | 只读用户 |
|------|:---:|:---:|:---:|
| 台账增删改查/导入导出 | ✓ | ✓ | 仅查看 |
| 菜单/字段配置 | ✓ | ✗ | ✗ |
| 用户管理/备份恢复 | ✓ | ✗ | ✗ |

## 九、注意事项

1. 账号密码请定期修改，勿告知无关人员。
2. 关键台账（人口、低保、三费）数据请及时录入，系统预警依赖台账数据。
3. 服务主机请勿连接互联网，避免村民隐私数据外泄风险。
4. 遇到问题先联系系统管理员，勿自行操作数据库文件。
