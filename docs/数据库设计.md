# 智慧乡村村务综合管理系统 - 数据库设计文档

文档编号：ZW-CW-20260731-DB · 存储：SQLite 单文件（`backend/data/village.db`）

## 一、数据分层

| 层 | 表 | 说明 |
|----|----|------|
| 系统基础表 | `sys_user` `sys_role` `sys_menu_config` `sys_oper_log` `sys_config` `sys_screen_config` | 用户、角色、菜单、审计日志、系统参数、大屏布局 |
| 文档与预警 | `t_file_archive` `t_warning` | 附件归档、智能预警 |
| 元数据表 | `sys_field_config` `sys_field_library` | 台账字段元配置（零代码引擎核心）、预置字段库 |
| 业务台账表 | 22 张 `t_*` | 三大类村务台账 |

## 二、系统基础表结构

### sys_user 用户表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| username | TEXT UNIQUE | 登录名 |
| password_hash / salt | TEXT | PBKDF2-SHA256 加盐哈希 |
| real_name | TEXT | 姓名 |
| role | TEXT | admin 超级管理员 / manager 普通管理员 / viewer 只读 |
| phone | TEXT | 手机号 |
| status | INTEGER | 1 启用 / 0 禁用 |
| last_login / create_time | TEXT | 最近登录 / 创建时间 |

### sys_menu_config 菜单配置表
| 字段 | 类型 | 说明 |
|------|------|------|
| id / code | / TEXT UNIQUE | 主键 / 菜单编码 |
| name | TEXT | 菜单名称 |
| parent_code | TEXT | 上级菜单（null 为顶级） |
| sort_order | INTEGER | 排序 |
| is_visible | INTEGER | 显示开关 |
| is_ledger | INTEGER | 1 台账菜单 / 0 功能页面 |
| table_name | TEXT | 台账关联物理表 |
| path | TEXT | 功能页面前端路由 |

### sys_field_config 台账字段元配置表（零代码引擎核心）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| menu_code | TEXT | 所属台账 |
| physical_field | TEXT | 物理列名（与台账表列一一对应） |
| display_label | TEXT | 显示名称 |
| data_type | TEXT | text / number / date / image / select |
| form_component | TEXT | 表单组件 |
| is_system | INTEGER | 1 系统内置（锁定）/ 0 自定义 |
| show_in_list / show_in_form | INTEGER | 列表/表单显示开关 |
| is_required | INTEGER | 是否必填 |
| sort_order | INTEGER | 顺序（列表/表单/导出同步） |
| is_deleted | INTEGER | 软删除（回收站） |
| options_json | TEXT | 下拉选项 JSON |

> 自定义字段新增时：`ALTER TABLE <台账表> ADD COLUMN ext_N TEXT`，物理列与元数据事务化创建，异常自动回滚；删除仅软删除，历史数据保留。

### sys_oper_log 操作审计日志表
`id, user_id, username, action, module, detail, ip, create_time`

### t_warning 预警信息表
`id, menu_code, ledger_name, item_id, warning_type, content, level(red/yellow), status(pending/handled/resolved/postponed), due_date, create_time, handle_user, handle_time, remark`

### t_file_archive 文档归档表
`id, file_name, file_path, file_size, file_ext, category, menu_code, villager_name, related_id, upload_user, upload_time`

## 五、年度数据封存

封存时对每张台账表创建 `{table}_{year}` 存档表并复制数据，随后清空原表，实现跨年数据隔离。封存操作前自动创建加密备份，可随时恢复。

## 六、安全设计

- 数据库单文件存储于服务主机，禁止直接暴露。
- 密码 PBKDF2-SHA256 加盐哈希存储。
- 身份证、手机号等敏感字段后端脱敏后输出（管理员编辑场景除外）。
- 所有写操作写入审计日志，不可删除。
