# 智慧乡村村务综合管理系统 - 部署运维手册

文档编号：ZW-CW-20260731-OP · 适用版本：V1.3（React 前端版）

## 一、部署场景

本系统为**局域网离线部署**，全部数据存储于村内服务主机，**禁止外网访问，禁止业务数据上传互联网**。断外网状态下系统所有功能完整可用。

## 二、硬件与系统要求

| 项目 | 最低要求 |
|------|----------|
| CPU | 双核及以上 |
| 内存 | ≥ 4G |
| 硬盘 | 空闲 ≥ 50G（存放数据库与附件） |
| 操作系统 | Windows 10 / Windows 11 |
| 客户端 | Chrome / Edge 浏览器即可，无需安装任何软件 |

## 三、服务主机部署流程

### 1. 安装 Python 运行环境

在服务主机安装 Python 3.10+（安装时勾选 "Add python.exe to PATH"）。

### 2. 部署程序包

将交付包解压到主机任意目录，例如 `D:\cw-village`。目录结构：

```
cw-village\
  backend\
    app\          # 后端代码
    data\         # 数据库 village.db、上传附件 uploads、备份 backups（自动创建）
    static\       # 前端构建产物
    requirements.txt
    run.py
```

### 3. 安装后端依赖

```bat
cd D:\cw-village\backend
pip install -r requirements.txt
```

### 4. 启动服务

方式一（Windows 一键启动，推荐）：

> 双击交付包根目录下的 `start.bat`，系统自动检测并安装依赖、启动服务、打开浏览器。

方式二（Linux / macOS 一键启动）：

```bash
./start.sh
```

方式三（手动前台运行，测试用）：

```bat
cd D:\cw-village\backend
python run.py
```

### 5. 设置固定内网 IP

将服务主机 IP 设置为静态地址，例如 `192.168.1.100`。修改 Windows 网络适配器 → IPv4 → 使用固定 IP。

### 6. 客户端访问

同一局域网内，其他电脑浏览器输入：`http://192.168.1.100:8000`

### 7. 初始化

首次启动自动创建数据库与 22 套台账表。使用默认管理员 `admin / admin123` 登录，进入"系统管理 → 用户账号管理"修改初始密码并创建村干部账号。

## 四、日常运维

### 数据备份

- **自动备份**：服务主机每日按"系统参数配置"中的备份时间自动加密备份（默认 02:30），备份保留天数可配置。
- **手动备份**：系统管理 → 数据备份恢复 → 一键手动备份。
- 备份文件存储于 `backend/data/backups/` 目录，加密打包。

### 数据恢复

系统管理 → 数据备份恢复 → 选择备份文件 → 恢复。恢复前系统自动保存当前数据快照，可回退。

### 年度数据封存

每年末在"数据备份恢复 → 年度数据封存"中封存本年度全部台账数据至独立年度表并清空当前台账，实现跨年数据隔离。封存前自动备份。

### 日志审计

所有新增、修改、删除、配置变更均永久记录于"系统管理 → 操作日志"，普通用户无法删除。

## 五、常见问题排查

| 现象 | 处理方式 |
|------|----------|
| 客户端无法访问 | 检查服务主机防火墙是否放行 8000 端口；确认主机 IP 为静态且与客户端同一网段 |
| 页面提示"登录失效" | 服务主机重启后请重新登录 |
| 上传文件丢失 | 检查 `backend/data/uploads` 目录空间 |
| 端口被占用 | 修改 `run.py` 中 port 参数 |
| 需要更换服务主机 | 停止服务后复制整个 `backend/data` 目录到新主机同路径，再启动 |

## 六、数据安全须知

1. 服务主机仅限内部办公网络接入，严禁暴露到互联网。
2. 数据库文件（`village.db`）禁止直接对外提供或拷贝外带。
3. 身份证、手机号等敏感信息在全系统自动脱敏展示。
4. 账号采用角色分级授权，只读用户无任何增删改权限。
